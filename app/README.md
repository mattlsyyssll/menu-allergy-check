# Menu allergy check for a parent

A parent photographs a restaurant menu, often in a language they do not read. The app marks every dish against the child's allergy list and writes the question to ask the waiter, in the menu's language and the parent's language.

The allergy list and the photo stay on the device. Only the dish names on the menu are sent to a cloud model, to look up typical recipes.

## What you get

- A saved allergy list (19 items: the US 9, the EU 14 with shellfish split into crustaceans and molluscs, plus buckwheat, kiwi, banana, peach and corn, and your own words), kept in this browser only.
- A menu photo (camera, file, or a built-in sample menu).
- One mark per dish. There are exactly three labels, and none says "safe":
  - **No listed allergen found**
  - **Ask the kitchen**
  - **Avoid**
- A chip on each dish showing which model decided it: this device or the cloud model.
- A "What left this device" panel with the exact text sent to the cloud, and a reminder that the list and photo are never sent.
- A waiter question in the menu's language and in the parent's language (English, Chinese, Spanish, French, Italian, Japanese, Thai).

## How the check works

1. On device: the built-in Chrome model reads the photo (ONE call) and returns dish names, English names and the ingredients printed on the menu.
2. On device: each dish is checked against the saved list and the hidden-sources table, using the printed text only.
   - An allergen printed on the menu gives **Avoid**.
   - A hit in the hidden-sources table (satay, papaya salad, mole, pesto, soy sauce, hoisin, oyster sauce, fish sauce, batter, pastry, mayonnaise and so on, for every item on the list) gives **Ask the kitchen**.
3. Cloud: ONE request with ALL dish names (printed name and English name) plus a fixed instruction goes to a Gemini model. The instruction is the same for every user and names all 19 allergen categories. For each dish the model returns a typical recipe and a rating for each category: usually, often, rarely or unknown.
4. On device: only the allergens on the saved list are read from the answer. **usually** gives **Avoid**. **often**, **unknown**, no rating, or a table hit gives **Ask the kitchen**.
5. Final label = the stricter of step 2 and step 4 (Avoid, then Ask the kitchen, then No listed allergen found). A cloud answer can never lower a mark set from the menu text.
6. Offline, cloud off or cloud failed: only steps 1 and 2 run. A dish with no printed ingredients gets **Ask the kitchen**. A dish the cloud does not know gets **Ask the kitchen** if it has no printed ingredients.
7. The waiter question is built from fixed, reviewed templates, not generated by a model, so the wording cannot drift.

See `DESIGN.md` for the on-device and cloud split, the privacy rule, the labels and the timeouts.

## How Firebase AI Logic hybrid inference is used

The app uses the `firebase/ai` SDK (`getAI`, `getGenerativeModel`, `InferenceMode`) and picks the mode by what the step may see:

| Step | Mode | Why |
|---|---|---|
| Read the menu photo | `ONLY_ON_DEVICE` | The photo and the allergy context must never fall back to the cloud. A failure shows as an error, not a silent upload. |
| Typical recipes for all dish names (one request per menu) | `ONLY_IN_CLOUD` | Needs broader knowledge of recipes. Receives dish names only; the match against the list happens on the device. |

On-device calls pass a JSON schema as `onDeviceParams.promptOptions.responseConstraint`, and each reply is checked through `response.inferenceSource` so the "decided on device / by cloud" chip comes from the SDK, not from a guess. The on-device model is warmed with `initializeDeviceModel` when the page opens (Chrome may need one tap the first time it downloads the model).

## Run it

Needs Node 22.12 or newer, and desktop Chrome with the built-in model (Prompt API with image input) for the on-device part.

```bash
npm install
cp .env.example .env.local   # optional: fill in Firebase config to turn the cloud step on
npm run dev                  # http://localhost:5173
npm test                     # unit tests (vitest)
npm run build                # type check and production build
```

With no Firebase config the app still runs the on-device part and shows "Cloud step: off". Dishes with no printed ingredients are then marked **Ask the kitchen**.

### Firebase setup (cloud step)

1. Firebase console: create a project and register a web app. Copy its config into `.env.local` (`VITE_FIREBASE_*`).
2. Console > AI Services > AI Logic > Get started > choose **Gemini Developer API** (free tier).
3. Console > App Check > APIs: set AI Logic to **Unenforced** for local use, or register an App Check debug token.

`VITE_CLOUD_MODEL` sets the cloud model (default `gemini-3.5-flash-lite`).

## Code layout

- `src/core/allergens.ts`: the 19 allergens, direct words and hidden sources in English plus ten more languages (`multilingual.ts`).
- `src/core/core.ts`: pure functions. Parse model JSON, apply the table, merge marks, build the cloud payload, write the waiter question.
- `src/pipeline.ts`: the step order. Talks to two small engine interfaces, so it is tested with fakes.
- `src/ai.ts`: the Firebase AI Logic wrapper.
- `src/runner/run.ts`, `run.html`, `scripts/`: dev-only batch runner for the test kit in `../kit`.
- `src/main.ts`, `src/image.ts`, `src/style.css`, `index.html`: the interface.
- `tests/`: unit tests, including that the cloud payload never holds the allergy list or image data.

## Privacy statement

- The allergy list is stored in this browser (`localStorage`) and is never uploaded.
- The menu photo is read on the device and is never uploaded.
- The only data sent to the cloud is the dish names on the menu (printed and English), in one request per menu. The exact text is shown in the "What left this device" panel. The request is the same for every allergy list, so it cannot reveal the list.
- No analytics, no accounts, no server of our own.

## Limits

Marks come from menu text, a built-in table and model guesses. They are not a guarantee. A hidden-sources table cannot cover every kitchen. Always ask the kitchen, and carry prescribed medicine.
