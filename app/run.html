Batch runner (dev server only; not in the production build)

Runs the same check as the app on kit menus, per allergy list. Records the label and decider per dish and the cloud request exactly as sent (one per menu, dish names only). Held-out menus (set 1, and set 2 = M25 to M32) are refused unless the address has ?final=1. The Download button also saves the run to the kit's runs/ folder (name from ?save=NAME, never overwrites).
